# 通用错题集

把用户提交的错题图片转成能够独立复习、打印和训练的正式错题集。核心目标是掌握知识并拓宽解题思路：识别错题涉及的具体知识和思维操作，用诊断小问区分可能的卡点，再用原创新题检验迁移。适用于选择、填空、计算、证明、阅读、写作、实验、编程及其他开放题；不要沿用某个考试的固定题型、选项规则或知识分类。

## 默认交付与范围

- 用户只需提供图片或图片文件夹；在已启用本技能的上下文中，这就是整理错题的输入，不要求先填表或提供OCR文本。
- 默认处理本次提交范围内的全部错题，交付一本完整PDF。只有用户明确要求样章或限定范围时才缩小任务；后续新增图片需增量识别、去重并更新整本书。
- 根据题面识别学科、水平和题型。能从图片判断的不要再问；没有明确年级、考试或官方大纲时，按题目实际知识分类，不虚构大纲归属。混合学科可先按学科分组，再按具体知识与思维操作分类。
- 能确定考试或课程范围时，先核对适用大纲、题型与评分规则，建立适合这批题目的知识框架。调查结果用于分类和解析；正式书中不附制作研究报告。
- 只有缺失信息会改变收录范围、题意或答案时才澄清，并继续不依赖该信息的工作。题面字迹模糊、截断或作答标记含义不清，不能以推测替代确认。
- 使用用户的语言与命名偏好。没有指定时，书名和文件名用“错题集”，不加“草稿”“首版”“最终版”“A4黑白版”等版本或格式标签。

## 图片识别与题目核对

1. 清点图片；按上下文拼接跨页题干、共用材料和后续选项，识别重复拍摄。保持题目、图表、选项与作答属于同一道题。
2. 结合视觉和OCR识别错题。红X是常见信号，不是所有资料的唯一规则；按实际批改标记及用户说明判断。若用户提交的是单独截出的错题，未画X也可收录。整张试卷无法确定错题范围时先询问，不把所有未标记题一概当错题。
3. 逐题核对完整题干、数字、单位、否定词、条件、公式、上下标、语言重音符号、化学式、代码缩进和图形约束。图示中没有的接触、平行、独立性等条件不能靠想当然补入。
4. 已知考试/教材可查官方大纲与公开原题；GitHub或其他公开题库可以辅助交叉验证，不是必需依赖，也不是正确性的保证。模考、自编题或找不到匹配来源时，优先确保与图片一致，再独立解答。比较选项内容后映射答案，不能直接套用题库字母。
5. 题干或选项不全时，只有在匹配证据充分且不存在不同版本混用时才能补齐；在聊天说明关键恢复情况。无法可靠恢复影响答案的内容时，先请求所需资料，不编造完整题目或宣称已经完成。

原始图片定位、识别置信度、题库匹配、选项映射和核对记录留在内部工作文件。PDF不放照片序号、坐标、OCR清单或核验标签。图形需忠实、清晰，不能将批改痕迹或错误草稿当成题目本身。

## 从错题到教学内容

以下是默认成品结构，本次用户的明确要求优先；详细质量要求见 [references/teaching-quality.md](references/teaching-quality.md)。

1. **原题与诊断**：每道题前写“本题考查的知识”，同时提供关键词和详细解释。解释必须写出知识是什么、适用条件是什么，以及本题要求完成哪些思维操作，而非只列标签。随后完整原题、选项/图表，再紧跟诊断小问。
2. **诊断参考答案**：必须有明确答案、理由或评价标准；放在该原题最后一部分所在页的紧接下一页。可以把上一页几道原题的小问答案集中列在页首，标明正式原题编号，再继续后续原题。不要提前泄漏答案。
3. **本类解题思路**：全部原题之后开始新页。给出尽可能多的有效解题角度，说明适用情形、操作步骤、理由、边界与常见陷阱。不为凑数量重复同一种方法。
4. **每道原题的答案与解析**：逐题完整推导、证据链或评分要点；说明哪些角度可迁移、哪些错误为何不成立。明确目标、定义域、量词、单位、边界、评分条件等。基于可见作答提出具体错因假设，用诊断小问验证，不能从一个红X断言学生一定缺乏某种能力。
5. **新题补练**：每类默认三道原创题，围绕同一核心知识考查不同表征、迁移或边界；不能全部只是换数字。题面不写知识提示、难点标签或答案线索。保持与用户水平和原题合理接近。
6. **新题答案与解析**：在本类全部新题结束后的下一页开始。知识说明放在这里；每题给答案、完整解析，并在有价值时给另一角度。开放题给参考答案、依据和评分量规，承认有效的不同表达，不硬凑唯一答案。

遇到原题本身不成立或有歧义，保留真实题面，在对应解析写出具体冲突、可得结论与必要解释。不要为了给一个选项而改题；必要建模条件须与原题已知条件区分。把编辑过程说明移到聊天，不删除影响求解的实质限制。

## 排版与生成

默认采用已确认的紧凑打印排版，用户可覆盖这些默认值：

- A4纵向、黑白/灰度，正文从9.5pt、12.6pt行距起；中文用正常宋体/衬线字体，英文用匹配衬线字体，标题适度加粗。嵌入字体并检查特殊字符。若用户对象或文字系统需要更大字号/其他字体，调整并在聊天说明。
- 第一页开始目录，目录页码/链接和PDF书签与分类一致。正文页眉只放书名或有效章节名，页脚只放页码；用细线与标题形成层次。
- 连续排多题，短选项横排、长选项按正常阅读顺序竖排。通常整道短题的知识、题干、选项和诊断同页；长材料题可跨页，诊断跟在题尾，答案仍从紧接下一页开始。不要为压页数删内容、任意缩小字号或强制一页一道题。
- 避免孤标题、拆断选项、图表裁切和重复空页。解题思路可接原题解析；原题解析可接新题。只对必要的题答分隔和分类起始分页。
- 成品只包含教学内容。不要在书中印制作声明、字体/打印说明、处理进度、版本说明、置信度、核验记录或说明本技能如何工作；这些信息通过聊天交代。

在PDF创建/编辑时，遵循当前环境可用的PDF技能与工具契约。常规内容可用随技能提供的排版工具；使用前读 [references/workbook-data.md](references/workbook-data.md)，按该内部数据格式填充内容后运行：

将下列脚本路径解析为本技能安装目录中的绝对路径；`work/`与`outputs/`属于当前任务目录。不要为运行脚本而把用户资料或交付物存入技能目录。

```text
python scripts/build_workbook.py work/workbook.json --output outputs/错题集.pdf --manifest work/layout.json
python scripts/check_workbook.py work/workbook.json --pdf outputs/错题集.pdf --manifest work/layout.json --report work/checks.json
```

如果复杂公式、文字系统或大图表不适合helper，换用合适的原生排版工具，仍执行同样的题答和完整性要求。不要把工具限制变成学科限制。

## 交付前验收

- 逐题独立解答并复核OCR。新题需复核全部选项、唯一性或评分量规；数学/实验/编程可用计算、枚举或运行代码验证关键结论，语言/人文题要核对材料证据与可接受答案范围。较复杂题目可以委派独立复核。
- 对照内部清单确认全部错题、知识说明、诊断问答、原题解析及每类新题/答案均保留。去重不能误合并不同版本或不同条件的题目。
- 渲染并视觉检查PDF：目录、正文字号、图表、特殊符号、选项顺序、题尾诊断和隔页答案。检查全部页面的整体布局，关键密集页放大看；修改后复查变化页。仅文本抽取成功不等于版式通过。
- 用实际文件确认页数、目录定位、嵌入字体和题答分页。若使用helper，运行checker；其通过只证明所覆盖的结构检查，不证明OCR或学科内容正确。
- 只交付正式PDF；可编辑源文件仅在用户需要时一并提供。聊天简要说明完成范围、关键内容问题或打印设置，链接实际保存的交付物，不把这些说明补回产品。
